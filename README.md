# tamil-input-engine-checkbox

[**Recommended**: Check this out if you want to understand what this project actually does.](https://triangulatedexistence.mataroa.blog/blog/a-proposal-for-indic-keyboard-interfaces/)

This website is inspired from the preprint "[Taravinyas: Mapping Paninian Phonology to Digital Logic for Continuous Touchscreen Input](https://doi.org/10.5281/zenodo.20467634)." The following website is the implementation of the input engine, in the modern Tamil script. [Check out this guide I made in order to navigate the website.](https://triangulatedexistence.mataroa.blog/blog/a-starter-guide-to-taravinyas/)

[Lastly, if you want to understand my coding choices or if you want to understand the implementation better, check out this blog of mine.](https://triangulatedexistence.mataroa.blog/blog/making-a-mathematical-model-for-better-indic-keyboards/)

Note: On Android, Chromium-based browsers may dismiss the keyboard when switching input layouts; Firefox for Android works as expected.

## Description of the folders

- css: All the CSS used, stored locally
- fonts: All the fonts used, stored locally
- uml-and-flow: The flow I use to make people understand my website and the mathematical framework
- ts: All the TS files in raw form and in JS form.
- tests: The sympy evaluator used to crunch out the boolean equations. Used for cross-checking the expressions in the TS files.
